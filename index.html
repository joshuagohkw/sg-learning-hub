      How to Get a Free Gemini API Key (5 minutes)

      Google Gemini offers a free tier that is more than enough for student learning sessions. Follow these steps:

      1. Go to Google AI Studio
        Open https://aistudio.google.com/apikey
        (Parents: sign in with your Google account. A personal Gmail account works fine.)
      2. Click "Create API Key"
        Click the blue "Create API key" button. If prompted, select "Create API key in new project" or choose an existing project.
      3. Copy your key
        Your key will look like: AIzaSy...
        Click the copy icon next to it.
      4. Paste it here
        Come back to this page, make sure Google Gemini is selected as the provider, and paste the key into the API Key field above.
      5. Click "Test Connection"
        This will verify your key works. You should see a green "Connected!" message.

      Free Tier Limits (more than enough!):

      • 15 requests per minute / 1,500 requests per day
      • 1 million tokens per minute
      • No credit card required
      • That means hundreds of AI-generated questions per day for free!

      For Parents:

      Your API key is stored only on this device in the browser's local storage. It is sent directly to Google's servers to generate questions — it is never shared with any third party. You can delete it anytime from this settings page.

      Using Anthropic Claude API

      Claude is a paid API. You'll need an Anthropic account with billing set up.

      1. Go to https://console.anthropic.com/settings/keys
      2. Click "Create Key" and copy it (starts with sk-ant-...)
      3. Paste it into the API Key field above

      Cost: roughly $0.001-$0.01 per question depending on model. A 30-question session costs about $0.03-$0.30.

      How It Works

      Local Bank Local — Built-in question generators with procedural randomisation. Always available, works offline. Covers Math, Science, English, Chinese, General Knowledge, and Brain Teasers.


      AI Generated AI — Uses AI to create unique, contextual questions tailored to the student's level and weaknesses. Requires internet and an API key. Falls back to local if AI is unavailable.


      Real Exam Exam — Real questions transcribed from actual 2025 Singapore school exam papers (shows the school and term it came from). Always available offline. Currently covers Primary 2-6 for English, Primary 2-5 for Math/Chinese, and Primary 3-5 for Science -- other levels/subjects use Local/AI until more papers are added.
